همگام‌سازی دوطرفه‌ی ووکامرس و غرفه‌ی باسلام: محصول یک بار ثبت می‌شود، در دو جا فروخته می‌شود و هیچ سفارشی گم نمی‌شود.

== Description ==

باسلام‌هاب فروشگاه ووکامرس و غرفه‌ی باسلام را دوطرفه همگام نگه می‌دارد. سر اطمینان رقابت می‌کند: هیچ داده‌ای بی‌صدا گم یا بازنویسی نمی‌شود، کارهای سنگین فقط در صف پس‌زمینه اجرا می‌شوند (روی هاست اشتراکی هم Timeout نمی‌خورد)، و هر خطا به فارسی ساده می‌گوید چه شد، چرا، و چه باید کرد.

= محصولات =
* ارسال تکی و گروهی محصولات ساده و متغیر (هر تنوع با قیمت و موجودی مستقل) به باسلام، بدون ساخت تکراری
* انتخاب فیلدهای همگام (مثلاً فقط قیمت و موجودی)
* نگاشت دسته‌ها با ویژگی‌های اجباری باسلام، قوانین قیمت سراسری و دسته‌ای با گردکردن
* تغییر خودکار ابعاد و حجم تصویر روی یک کپی؛ هر تصویر فقط یک بار آپلود می‌شود
* اتصال محصولات موجود غرفه با پیش‌نمایش «قطعی / مشکوک / بدون جفت»
* ایمپورت کل غرفه به ووکامرس با عکس، قیمت، موجودی، دسته و تنوع‌ها

= سفارش‌ها و موجودی =
* ثبت خودکار سفارش‌های باسلام در ووکامرس با برچسب و شماره‌ی باسلام، هرگز تکراری
* وضعیت دوطرفه: «تأیید سفارش» و «ثبت ارسال» با کد رهگیری از داخل سایت
* تطبیق شبانه: سفارش‌های ۷ روز اخیر هر شب مقایسه و جاافتاده‌ها ثبت می‌شوند
* موجودی دوطرفه با انتخاب مرجع (سایت یا باسلام) و موجودی اطمینان

= فروش و گزارش =
* داشبورد فروش دوکاناله: فروش سایت و باسلام کنار هم، سهم باسلام، سود باسلام پس از کمیسیون و پرفروش‌های هر کانال
* هشدار کمبود موجودی برای کالاهای باسلام، پیش از آن‌که سفارشی بیاید که نتوانی بفرستی
* گزارش هفتگی شنبه‌ها در بله یا تلگرام: فروش دو کانال، سفارش جاافتاده، خطاها و کالاهای رو به اتمام
* مرکز لاگ فارسی با دلیل، راه‌حل و دکمه‌ی تلاش مجدد
* اعلان بله و تلگرام برای سفارش جدید، خطاهای مهم و نتیجه‌ی تطبیق شبانه
* داشبورد با «امروز چی شد»، امتیاز سلامت از ۱۰۰، سلامت سیستم، پوسته‌ی روشن و تیره
* اعلان زنده‌ی سفارش باسلام داخل پنل
* حالت نمایشی با داده‌ی نمونه برای دیدن همه‌چیز پیش از اتصال

باسلام‌هاب فقط از API رسمی باسلام استفاده می‌کند؛ بدون اسکرپینگ.

== External services ==

این افزونه برای کار به این سرویس‌ها وصل می‌شود. هیچ داده‌ای جز آنچه اینجا آمده فرستاده نمی‌شود.

* **API رسمی باسلام** (`https://openapi.basalam.com`) — برای ساخت و به‌روزرسانی محصولات غرفه، خواندن محصولات و سفارش‌های غرفه و تغییر وضعیت سفارش. داده‌های فرستاده‌شده: اطلاعات محصولات (نام، توضیحات، قیمت، موجودی، وزن، ابعاد، تصاویر، دسته)، کد رهگیری و روش ارسال سفارش، و توکن دسترسی که خودت وارد می‌کنی. فقط وقتی فرستاده می‌شود که افزونه را به غرفه‌ات وصل کنی. [شرایط استفاده](https://basalam.com/terms) · [حریم خصوصی](https://basalam.com/privacy)
* **فایل‌های تصویر باسلام** (`statics.basalam.com`) — فقط هنگام «ایمپورت غرفه»، برای دانلود عکس محصولات خود غرفه.
* **Bot API بله** (`https://tapi.bale.ai`) و **Bot API تلگرام** (`https://api.telegram.org` یا آدرس واسطی که خودت وارد کنی) — فقط اگر اعلان را روشن کنی؛ متن اعلان (شماره و مبلغ سفارش، نام و شهر گیرنده، یا متن خطا) به گفتگویی که تعیین کرده‌ای فرستاده می‌شود. [شرایط بله](https://bale.ai/terms) · [شرایط تلگرام](https://telegram.org/tos)

== Installation ==

1. ووکامرس را نصب و فعال کن.
2. افزونه را از «افزونه‌ها › افزودن › بارگذاری» نصب و فعال کن.
3. در پنل توسعه‌دهندگان باسلام یک توکن شخصی با دسترسی «محصولات غرفه» و «سفارش‌های غرفه» بساز.
4. باسلام‌هاب › تنظیمات: توکن را بچسبان و «ذخیره و تست اتصال» را بزن.
5. باسلام‌هاب › نگاشت دسته‌ها: برای دسته‌های ووکامرس، دسته‌ی باسلام را انتخاب کن.
6. اگر غرفه‌ات از قبل محصول دارد، اول «اتصال محصولات غرفه»؛ بعد «ارسال گروهی» یا «ایمپورت غرفه».

اگر WP-Cron روی هاستت خاموش است، از هاستینگ بخواه هر ۵ دقیقه یک Cron Job برای `wp-cron.php` بسازد؛ صفحه‌ی سلامت داشبورد این را تشخیص می‌دهد.

== Frequently Asked Questions ==

= محصول یا سفارش تکراری ساخته نمی‌شود؟ =
نه. هر محصول و سفارش در جدول اتصال با شناسه‌ی باسلام ثبت می‌شود؛ حتی اگر پاسخ باسلام در راه گم شود، پیش از ساخت دوباره با SKU جستجو می‌شود.

= اگر سایت چند ساعت قطع باشد، سفارش‌ها گم می‌شوند؟ =
نه. دریافت سفارش‌ها با هم‌پوشانی انجام می‌شود و تطبیق شبانه هم هر شب سفارش‌های ۷ روز اخیر را مقایسه می‌کند.

= روی هاست اشتراکی ضعیف کار می‌کند؟ =
بله. هیچ درخواستی از صفحه‌ی ادمین مستقیم به باسلام نمی‌رود؛ همه‌چیز در صف پس‌زمینه با یک کار در هر لحظه اجرا می‌شود و محدودیت درخواست باسلام (429) رعایت می‌شود.

= چرا اعلان تلگرام نمی‌رسد؟ =
بیشتر هاست‌های داخل ایران به تلگرام دسترسی ندارند. از بله استفاده کن یا آدرس یک واسط امن را وارد کن.

= قبلاً «سلام‌هاب» نصب کرده بودم =
باسلام‌هاب همه‌ی اطلاعات را خودکار منتقل و نسخه‌ی قدیمی را غیرفعال می‌کند. بعد از آن می‌توانی افزونه‌ی قدیمی را حذف کنی.
